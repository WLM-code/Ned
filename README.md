# Traangas Studiehulp

Leer-app voor het boek *Dansen tussen wolken van traangas* (Monique Samuel).
Je beantwoordt stap voor stap vragen, bouwt zo je eigen samenvatting op en sluit af met een oefentoets.

Alles zit in één bestand, `index.html`. Er is geen build en geen server nodig.
Je antwoorden worden alleen in je eigen browser bewaard (localStorage).

## Zelf openen

Dubbelklik op `index.html`. Voor de lettertypen heb je internet nodig, anders gebruikt de browser een standaardlettertype.

## Op GitHub Pages zetten

1. Maak op github.com een nieuwe repository, bijvoorbeeld `traangas-studiehulp`.
2. Upload `index.html` en `README.md` (knop *Add file* > *Upload files*) en kies *Commit changes*.
3. Ga naar *Settings* > *Pages*. Kies bij *Source* de optie *Deploy from a branch*, kies de branch `main` en de map `/ (root)`, en klik op *Save*.
4. Na een minuut staat de app op `https://JOUWNAAM.github.io/traangas-studiehulp/`.

## Aanpassen

De vragen, modelantwoorden en toetsvragen staan bovenin het script in `index.html` in de lijsten `STEPS`, `QUIZ` en `TALK`.
